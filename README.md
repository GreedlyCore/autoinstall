# Ubuntu Auto-Installation

A collection of scripts for setting up Ubuntu utilities. Run scripts individually to install the components you need.

The version column reflects explicit targets and notes in the current files, not a verified compatibility matrix. **Not specified** means the script does not declare supported Ubuntu releases. The previous README reported project-level testing on Ubuntu 20.04 and 22.04. (TODO: strictly mention ubuntu versions, and update anything to modern ubuntu26)

Replaces user/root Zsh and Starship configuration, changes login shells, and deletes existing Neovim configuration/data/cache. Backs up Ghostty configuration.
